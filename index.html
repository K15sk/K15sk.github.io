Triagem automática de logs com IA

Nos CTFs eu analisava logs de servidor na mão, com grep e sort, para descobrir se alguém tinha invadido. Transformei esse processo em uma automação: um script em Python lê o log de acessos SSH, encontra os padrões de ataque e gera um relatório em português que um gestor consegue entender. Com uma chave da API do Claude, o relatório ganha um resumo executivo com as três ações mais urgentes.

4tipos de alerta: força bruta, possível invasão, acesso de madrugada e contas mais visadas
0bibliotecas externas: roda com Python puro
3níveis de risco no relatório: alto, médio e baixo
$ python3 triagem_logs.py exemplos/auth.log --ano 2026
Risco ALTO: Há indício de que um atacante conseguiu entrar.
2 IP(s) de força bruta · 1 possível(is) invasão(ões) · 2 acesso(s) de madrugada
Relatório salvo em relatorio.md

Decisões de projeto:

  • A detecção usa regras, que são previsíveis e fáceis de auditar. A IA entra só para traduzir o resultado em linguagem de negócio.
  • Para a IA vão só estatísticas, nunca o log completo, para não expor dados sensíveis.
  • A primeira versão marcava como invasão qualquer funcionário que errava a senha uma vez. A regra passou a exigir 3 erros na hora anterior, eliminando esses falsos positivos.

Como foi construído: com o Claude como assistente de programação, partindo de uma análise que eu já fazia manualmente. Usar IA para transformar um processo manual em ferramenta foi o objetivo do projeto.
